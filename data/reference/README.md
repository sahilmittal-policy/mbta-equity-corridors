# Reference data

Numbers in this folder are **not** direct pipeline outputs. They are recovered
from published project artefacts and are labelled accordingly.

## `top15_boardings_digitized.csv`

The presentation's "Why These Corridors Matter" chart plots corrected average
weekday boardings for all fifteen top equity-volume routes, but only the three
ENG routes had their corrected values written down in the surviving text.

Values for the other twelve routes were read off the bar chart in
`docs/slides/` and are accurate to roughly ±150 boardings. They exist so the
headline figure can be regenerated, not so anyone can cite them. The
`precision` column marks which is which.

The system-wide bus median referenced on that slide is approximately 2,400
average weekday boardings.
